# 隐私、存储与备份

READ 是本机服务，但翻译和问答会将相应任务及模型需要的论文内容交给使用者登录的 Codex。它不等于完全离线工具。是否可以处理未公开论文、审稿材料或涉密内容，应按使用者自己的授权和服务约定决定。

## 数据在哪里

| 位置 | 内容 | 公开发布 |
| --- | --- | --- |
| `.reader-data/documents/` | 原始 PDF、解析正文、图像、译文、问答副本、阅读进度、论文对话绑定、重排备份 | 排除 |
| 文档中的 `paper-resources/` | 首次登记/更新生成的原文资料快照和清单 | 排除 |
| `.reader-data/settings.json` | 当前翻译档位等本地设置 | 排除 |
| `.reader-data/jobs.json` | 最近任务、问题、状态、模型元数据、对话编号和错误 | 排除 |
| `.reader-runtime/` | 日志、PID 与开发过程运行产物 | 排除 |
| `output/`、`tmp/` 等本地输出 | 回归报告、裁图、截图及临时材料 | 排除 |
| `.env` / 自定义配置路径 | 本地路径与个人覆盖配置 | 排除，只发布 `.env.example` |
| 浏览器站点数据 | 每篇论文未发送的草稿、引用及界面偏好 | 不随源码发布 |
| 使用者的 Codex 状态目录 | Codex 自己的认证和原生对话历史 | 不复制到本项目或发布包 |

数据目录可由 `READER_DATA` 更改。任何自定义导出、Markdown、日志和截图也可能包含私人资料，即使它们不在上述路径里也要单独检查。

论文问答通过资料包路径回查原文，不在每次提问时重复拼接整个论文与全部历史。持久对话有各自上下文，历史很长时模型仍可能压缩上下文并重新读取资料，隔离论文不表示上下文长度无限。

网页显示完整阅读问答的本地副本；原生 Codex 历史另存，可能包含登记、结构化翻译等网页隐藏的内部任务。当前安装版本支持时可在 Codex App 查看对应原生对话。删除网页数据或本地论文不会自动删除 Codex 历史，删除 Codex 对话也不等于清除本地副本。

## 网络边界

服务仅监听回环地址并校验 Host/Origin，网页使用本地资源。不要把端口代理到公网或局域网；当前实现没有账户鉴权。

问答会按问题需要请求使用可用的搜索工具。提示词要求仅用必要的公开题名、作者/方法名检索，不向外站提交全文、私有选文、聊天记录、路径或凭据；这是模型行为约束，不是独立网络防火墙，也不应作为处理机密资料的唯一保障。翻译与登记轮次要求只用本地论文证据，不把检索内容混进译文。

论文、网页和源码内容都作为不可信证据，不是操作指令；默认桥接请求只读沙箱、不请求文件写入。只读权限仍意味着模型可以读取其授权环境中的资料，不能把它理解为每篇论文独立的操作系统隔离。

## 备份与迁移

1. 等待任务结束并停止服务，复制完整数据目录到私人备份位置。不要只备份 `document.json`，它引用的图像、原 PDF 和资料快照也需要保留。
2. 保持目录结构恢复，设置 `READER_DATA` 指向恢复目录。浏览器草稿另存于站点数据，换浏览器或端口时不会自动迁移。
3. 原生对话归属于创建时的 Codex 账户和状态环境。复制阅读器数据不会转移对话所有权，也不应通过共享登录目录来迁移给其他人。
4. 跨机器或改变资料绝对路径后，已有原生历史可能引用旧路径。当前未承诺自动修复所有旧路径；先保留原备份、核查登记状态，必要时在新环境重新登记一份论文。

重排会先生成隔离结果、校验资源并保存 JSON 备份，再替换文档。内容变化的旧译文进入归档，不直接错绑新正文。不要把这类同盘备份当成独立灾备；删除数据目录会一并删除它们。

## 公开反馈前

使用合成短文与人工生成的测试图复现问题。检查复制的错误信息、控制台、屏幕截图和附件，移除姓名、邮件、绝对路径、对话编号、私有题名/段落、Cookie 和 token。不要上传 `.reader-data/`、Codex 状态目录或未审查的完整日志。
